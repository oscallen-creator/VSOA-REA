# Image tools and metadata/privacy inventory (IMG, META)

Source: Tangerine 2.0.4 strings (`S:` line in strings.txt), small-string literals (`L:` address), camel.txt type names, and the two bundled ExifTool scripts (read for behavior only). Numeric ranges, preset lists and defaults are mostly NOT recoverable statically; they are marked `unknown` and listed at the end.

## Overview
Tangerine's file-tool panel (`FileToolOptionsWindowController`, tool ids: `resizeImage`, `compress`, `cropImage`, `editImage`, `annotateImage`, `createCollage`, `frameImage`, `redactImage`, `readQRCode`, `removeMetadata`) opens an options window per tool. Every image tool writes a NEW file beside the original (original never modified; needs folder-access grant, "Tangerine saves results beside the originals"). Output suffixes seen: `-clean.` (metadata), `-compressed.`, `-edited.` ; progress titles: "Resizing images", "Cropping image", "Compressing", "Annotating photo", "Redacting photo", "Creating collage", "Reading QR codes", "Adding background", "Saving metadata". Primary buttons: "Apply" (generic), "Save", "Reset", "Remove All", "Create Collage", "Save Annotated Copy", "Save Redacted Copy", "Save Edited Copy", "Save with Background". Gating: Tangerine gates tools behind "Unlock" (full version / "free uses left"); FileChanger is fully unlocked, ignore.
Native route for all image work: ImageIO + CoreImage + CoreGraphics + Vision + PDFKit + AVFoundation. Tangerine itself uses ImageIO ("ImageIO could not create the compressed JPEG"), CoreImage filters (adjust), `cwebp`/ffmpeg only for WebP/animated/video; the replica avoids those.

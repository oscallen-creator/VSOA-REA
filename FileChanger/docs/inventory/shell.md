# Shell, UX and key-binds inventory (prefix SHL)

Source: Tangerine 2.0.4 (`com.th.Tangerine`). Evidence tags: `observed` = literal text/resource/disassembled constant seen; `inferred` = from type names or neighbouring literals; `unknown` = needs runtime observation.
Cites: `S:<line>` strings.txt, `L:<addr>` smallstrings, `D:<addr>` disassembly constant, `R:` bundle resource, `P:` saved prefs.
Gating note (the only paywall item): Tangerine gates "Unlimited conversions and tools" and "Convert multiple files at once" behind a one-time "Unlock" (free-use counter, S:28507-28510). FileChanger is fully unlocked, so no counter, no Unlock menu item, no paywall window.

## Overview
Tangerine is an `LSUIElement` menu-bar agent (no Dock icon). A global drag monitor (DragGestureMonitor) watches for the user dragging files anywhere (Finder, Desktop, other apps). While a file drag is in progress the user **taps a modifier combination** (not holds) and a radial "wheel" (fan of petals) appears around the cursor. There are **three wheels**, each with its own user-configurable modifier combination: Conversion (default Shift), Tools (default Command, migrated), Actions (default Control). Dropping the files on a petal runs the format conversion, a file tool, or a file action. Results are written **next to the original** (security-scoped folder access is requested once). Tools with options open a tool window (FileToolOptionsPanel). "Float" is a floating stack/shelf of file thumbnails with paper-clip visuals, created from the Actions wheel. A Welcome window teaches the gesture with a practice wheel. Settings is a column (sidebar) window.
